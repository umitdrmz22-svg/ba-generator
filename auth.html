BA Studio Sichere Benutzerverwaltung

Benutzerkonto und Firmenbereich

Anmelden oder registrieren

Nach der Registrierung wird ein eigener Firmenbereich angelegt. Rollen für Ersteller, Prüfer und Freigeber werden später innerhalb dieses Bereichs vergeben.

Technische Konfiguration fehlt.
Für echte Benutzerkonten müssen die Supabase-Verbindungsdaten im Deployment hinterlegt und das SQL-Schema ausgeführt werden.

Passwörter werden nicht von BA Studio gespeichert. Authentifizierung und Sitzungen werden über Supabase Auth verarbeitet. Berechtigungen für Firmendaten werden zusätzlich durch Row Level Security abgesichert.
